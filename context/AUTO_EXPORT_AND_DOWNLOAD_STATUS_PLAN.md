# 📋 IMPLEMENTATION PLAN: Auto-Export Reports & Download Status Indicator

## 1. Overview & Objective
When an **`ActionNode`** triggers a `fundamental_report` or a file is generated by Scriffle:
1. **Automatic Disk Export**: Automatically generate and save the standalone HTML/PDF document to disk at `reports/{project_name}/{symbol}_Fundamental_Brief.html` so the user does not need to manually trigger print/save to get the file.
2. **Download / Generation Status Indicator**: Add a clear status badge on the **`FileNode`** card (`🟢 Saved to /reports` vs `⚪ Online / Web Only` vs `📥 Downloaded`) to make it immediately clear whether the file is already stored locally on disk.
3. **Open Location Support**: Clicking "Open Location" opens the exact `reports/{project_name}/` folder on the user's operating system.

---

## 2. Architecture & File Structure

### Directory Layout
```
hackathon/
└── reports/
    └── {project_name}/             # Sanitized canvas/project name (e.g. "banking_sector_trio")
        └── {symbol}_Fundamental_Brief.html (standalone document with embedded styling)
```

### Affected Files
1. `src/server/services/reportExporter.ts` (New service):
   - Generates the standalone HTML document for any symbol.
   - Ensures directory `reports/{project_name}` exists on disk.
   - Saves file to `reports/{project_name}/{symbol}_Fundamental_Brief.html`.
   - Returns absolute disk path, relative URL, file size, and timestamp.
2. `src/server/services/graphEngine.ts`:
   - Calls `exportReportToFile(canvas.name, symbol)` when `fundamental_report` action runs.
   - Creates the `FileNode` with `isDownloaded: true`, `savedLocally: true`, `filePath`, and `fileUrl`.
3. `src/types/canvas.ts`:
   - Extend `FileConfig` with `isDownloaded?: boolean`, `downloadedAt?: string`, `savedLocally?: boolean`.
4. `src/components/canvas/nodes/FileNode.tsx`:
   - Render a status badge:
     - `🟢 Saved in /reports` (if `savedLocally: true` or `isDownloaded: true`)
     - `⚪ Cloud link` (if only web URL)
   - When user clicks "Open / Download", toggle `isDownloaded: true` and persist via `PATCH /api/canvas/nodes/:id`.
5. `src/app/api/export/report/route.ts`:
   - Support query param `?download=true` to send standard `Content-Disposition: attachment; filename=...`.

## 3. Step-by-Step Implementation Steps

### Step 1: Types Extension (`src/types/canvas.ts`)
Add status fields to `FileConfig`:
```typescript
export interface FileConfig {
  fileName: string;
  fileUrl: string;
  filePath?: string;
  fileSize?: string;
  fileCategory?: FileCategory;
  extension?: string;
  caption?: string;
  isDownloaded?: boolean;
  savedLocally?: boolean;
  downloadedAt?: string;
  createdAt?: string;
}
```

### Step 2: Auto-Exporter Service (`src/server/services/reportExporter.ts`)
- Function `saveReportToDisk(projectName: string, symbol: string)`:
  - Sanitizes `projectName` into safe directory name (`/reports/banking_sector_trio/`).
  - Renders the full standalone HTML brief (with embedded styling & fonts).
  - Writes the file to `<cwd>/reports/<project_slug>/<symbol>_Fundamental_Brief.html`.
  - Calculates file size (e.g. `18.4 KB`).
  - Returns metadata `{ filePath, relativeUrl, fileSize, savedLocally: true }`.

### Step 3: Graph Engine Integration (`src/server/services/graphEngine.ts`)
- In `graphEngine.ts`, update `action === 'fundamental_report'`:
  - Fetch canvas name from `canvas.name`.
  - Call `saveReportToDisk(canvas.name, curEvent.symbol)`.
  - Spawn `FileNode` with:
    ```typescript
    configJson: JSON.stringify({
      fileName: `${report.symbol}_Fundamental_Brief.html`,
      fileUrl: exportResult.relativeUrl || `/api/export/report?symbol=${report.symbol}`,
      filePath: exportResult.filePath,
      fileSize: exportResult.fileSize,
      fileCategory: 'document',
      savedLocally: true,
      isDownloaded: true,
      caption: `Auto-saved to reports/${projectSlug}/ at ${timestamp}`,
    })
    ```

### Step 4: UI Download Status Indicator (`src/components/canvas/nodes/FileNode.tsx`)
- Display a tactile status badge in the `FileNode` card:
  - **Saved locally badge**:
    ```tsx
    <span className="flex items-center gap-1 text-[9px] font-semibold text-emerald-600 dark:text-emerald-400 bg-emerald-50 dark:bg-emerald-950/40 border border-emerald-200 dark:border-emerald-800/60 px-1.5 py-0.5 rounded-md">
      <MingIcon name="check_circle_line" size={10} />
      Saved in /reports
    </span>
    ```
  - **Action Button Download trigger**: Clicking the external link / download button updates node status to `isDownloaded: true`.

### Step 5: Verification & Testing
- Run engine test `bun run src/server/test-engine.ts` or trigger simulation bar (`BBCA +6.2%`).
- Verify folder `reports/{canvas_name}/` is created on disk with the report file.
- Verify `FileNode` displays the `Saved in /reports` status badge.
- Verify "Open location" opens the local folder.
